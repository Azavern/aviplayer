# aviplayer

Pemutar video Android untuk penggunaan pribadi: memutar file video lokal di HP (offline, tanpa streaming).

- Nama aplikasi & repo resmi: **aviplayer**
- Target perangkat utama: Redmi Note 11 (Android 12)
- Dokumen proyek (PRD, blueprint, UI, workflow) berada di folder induk `AVP/`

Repositori ini berisi source code aplikasinya. Status: Milestone 0 (fondasi proyek).

**Cara build di laptop: lihat [SETUP.md](SETUP.md).** Model kerja: source ditulis Ryn dan di-push ke repo ini; build & run dilakukan pemilik via Android Studio (`git pull` tiap ada perubahan).
